# Bravura notation glyphs

These PNGs are rasterized from **Bravura**, the SMuFL reference music font by Steinberg
Media Technologies GmbH. Plus2 Midi Player engraves its Score View with the same font, so
the shared score view uses these glyphs to match it.

Source: `Plus2 Midi Player/assets/font/Bravura.otf`
Codepoints: SMuFL U+E050, U+E062, U+E0A2-U+E0A4, U+E240-U+E243, U+E260-U+E262,
U+E4E3, and U+E080-U+E089.
